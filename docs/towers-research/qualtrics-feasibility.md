# Qualtrics integration feasibility

This is the original feasibility note. See the [ClipBridge study setup](../../README.md#tower-of-hanoi-study) for the hosted iframe and manual code handoff.

Research checked September 24, 2026. **Verdict: feasible if Lauren’s Qualtrics account permits custom HTML and JavaScript.** The lowest effort route is to put the game in one Qualtrics question and save its results as embedded data in the same survey response. An iframe is possible, but adds hosting and cross-window communication.

## Recommended route: game inside a survey question

1. In Survey Flow, define researcher fields before the game block: completion status, elapsed milliseconds, successful moves, invalid moves, and total attempts. Add a compact move sequence only if the research needs it. For the New Survey Taking Experience, define JavaScript-set fields with the `__js_` prefix (for example, `__js_hanoi_elapsed_ms`), then use `Qualtrics.SurveyEngine.setJSEmbeddedData("hanoi_elapsed_ms", value)` in the question code. Qualtrics includes defined embedded data in response data and exports. [Embedded Data](https://www.qualtrics.com/support/survey-platform/survey-module/survey-flow/standard-elements/embedded-data/) · [University of Minnesota Qualtrics guidance](https://it.umn.edu/services-technologies/resources/qualtrics-designing-accessible-surveys)
2. Put the game markup in one question’s HTML view. Put the game behavior in that question’s JavaScript editor, initializing it when the question is ready. Qualtrics explicitly supports custom question JavaScript and recommends its JavaScript editor for this code. [HTML View](https://www.qualtrics.com/support/survey-platform/survey-module/editing-questions/formatting-questions/) · [Add JavaScript](https://www.qualtrics.com/support/survey-platform/survey-module/question-options/add-javascript/)
3. Put the game-scoped CSS from `styles.css` in Look & Feel → Custom CSS. Qualtrics accepts CSS there or a link to an externally hosted CSS file. [Survey Style & Motion](https://www.qualtrics.com/support/survey-platform/survey-module/look-feel/fonts-and-colors/)
4. Start a browser timer on the game’s **Start** click. On completion, record the elapsed time and move counts into the Qualtrics fields, then let the participant advance. Qualtrics’ built-in Timing question measures time on a survey page; it would include any delay before Start and after winning, so it is not an exact substitute for this task timer. [Timing Question](https://www.qualtrics.com/support/survey-platform/survey-module/editing-questions/question-types-guide/advanced/timing/)
5. Preview in the exact survey layout and account that will collect responses. Complete a game, submit the survey, and inspect the exported response fields. New surveys use the New Survey Taking Experience by default; it supports custom HTML/CSS/JavaScript, but uses a different page structure than the legacy layout. [New Survey Taking Experience](https://www.qualtrics.com/support/survey-platform/survey-module/look-feel/simple-layout/)

## What has to change in this repo

`index.html` is now a complete standalone page that loads `styles.css` and `game.js`, so it can be opened locally in a browser. For Qualtrics, `game.js` should instead initialize against that question’s own elements, and the HTML/CSS should be pasted into the appropriate Qualtrics editors. These are packaging changes alongside Lauren’s requested gameplay changes.

For the data, count a legal transfer as one successful move and a larger-on-smaller attempt as one invalid move. Define total attempts as their sum. Keep the metrics out of the visible game UI; Qualtrics can store them with the response for the researcher. Browser-side code and data can still be inspected by a technically skilled participant, so this is display privacy, not a secrecy guarantee.

## Constraints that determine whether it works

- **Account permissions:** Qualtrics requires **Allow JavaScript** for question scripts and **Allow All HTML Markup** for custom HTML. Free/trial accounts do not enable custom code in live or preview surveys. Lauren should check these permissions with her institution’s Qualtrics administrator. [User permissions](https://www.qualtrics.com/support/survey-platform/sp-administration/managing-users/user-permissions/) · [Free accounts](https://www.qualtrics.com/support/survey-platform/managing-your-account/trial-accounts/)
- **Saving:** Qualtrics saves progress when the respondent goes to the next survey page. Results set in the browser on the game page can be lost if the respondent closes the tab before advancing. Put a clear continuation step after completion; decide whether partial attempts matter to the study. [Incomplete Survey Responses](https://www.qualtrics.com/support/survey-platform/survey-module/survey-options/partial-completion/)
- **Move log size:** Qualtrics documents a 20 KB ceiling for an embedded data value. A compact sequence is more suitable than verbose JSON, and the exact capacity of JavaScript-set fields in Lauren’s survey layout should be checked in a pilot. Counts and elapsed time are small. [Embedded Data limits](https://www.qualtrics.com/support/survey-platform/survey-module/survey-flow/standard-elements/embedded-data/)
- **Layout compatibility:** Qualtrics says the New Survey Taking Experience supports custom code but changed its HTML structure and does not preload jQuery. This game uses plain JavaScript, which helps. Any code that targets Qualtrics’ own buttons or page structure must be tested in that layout. [New Survey Taking Experience](https://www.qualtrics.com/support/survey-platform/survey-module/look-feel/simple-layout/)

## Iframe alternative

Host a complete HTTPS game page elsewhere and place it in an iframe in the survey question. To save game results in the same Qualtrics response, the hosted game must send a completion message to the parent survey page, and question JavaScript must receive that message and set the embedded data fields. Cross-origin frames cannot simply read or write each other’s page state; `postMessage` is the browser mechanism, with an exact target origin and origin checks. This route still needs Qualtrics custom code permissions plus external hosting. [Qualtrics HTML view](https://www.qualtrics.com/support/survey-platform/survey-module/editing-questions/rich-content-editor/rich-content-editor-overview/) · [MDN postMessage](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage)

## Pilot decision

The first practical check is whether Lauren can see a question’s JavaScript editor and use HTML view in her Qualtrics account. If yes, build the in-question version and run one submitted pilot response. Confirm the game appears, the task timer starts on Start, counts remain hidden, and all fields appear in Data & Analysis/export. The `setJSEmbeddedData` field mapping should be confirmed against her survey’s layout during that pilot; Qualtrics’ support page links to an API reference that was unavailable during this research.
